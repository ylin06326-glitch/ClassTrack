> **版本**: v1.1.0

---

## 一、项目定位

**项目名称**: ClassTrack（班级作业分组管理系统）

**一句话描述**: 面向中小学教师的班级作业分组管理Windows桌面工具，帮助教师高效完成学生分组、日常作业等级登记与台账导出。

**核心价值**:
- 将教师从纸质/Excel手工作业管理中解放出来
- 可视化拖拽分组，直观高效
- 一键导出标准报表，方便期末汇总与家长沟通
- 全部数据本地存储，保护学生隐私安全

---

## 二、目标用户

| 维度 | 描述 |
|------|------|
| **主要用户** | 中小学学科教师（班主任、语文/数学/英语教师） |
| **年龄范围** | 25-60岁（特别适配中老年教师操作习惯） |
| **技术能力** | 基础电脑操作能力（会用Excel、浏览器） |
| **使用场景** | 课堂办公、办公室备课、期末成绩汇总 |
| **班级规模** | 50-60人标准班级 |

---

## 三、总体目标

1. **功能完整**: 覆盖学生导入→分组→作业登记→报表导出全流程
2. **操作简单**: 中老年教师5分钟内可上手，拖拽即用
3. **视觉友好**: 简洁高级+柔和卡通童趣风，低视觉负担
4. **数据安全**: 纯本地存储，无云端上传，保护学生隐私
5. **绿色免装**: Windows绿色免安装版本，即下即用

---

## 四、技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **后端框架** | Python 3 + Flask | 轻量本地Web服务 |
| **数据库** | SQLite3 | 本地嵌入式数据库 |
| **前端UI** | HTML5 + CSS3 + Vanilla JS | 单页应用，卡通童趣风 |
| **Excel处理** | pandas + openpyxl + xlrd | 支持.xls/.xlsx读写 |
| **桌面打包** | PyInstaller | 单文件exe绿色发行 |
| **浏览器** | 系统默认浏览器 | 免安装运行环境 |

### 性能标准
- 60人名单导入 < 3秒
- 拖拽操作响应 < 100ms
- Excel导出 < 5秒
- 应用启动 < 2秒

### 质量标准
- 代码模块化拆分，注释完整清晰
- UI适配1024×768及以上分辨率
- 窗口自适应缩放，元素不错位
- 预留后续迭代拓展接口

## 六、项目约束

1. **平台限制**: 仅支持Windows 10/11
2. **网络要求**: 无需网络连接（纯本地运行）
3. **数据隐私**: 所有数据仅本地SQLite存储，无任何网络传输
4. **依赖管理**: 最小化第三方依赖，优先使用Python标准库
5. **分发形式**: 源码 + PyInstaller打包exe双形式
