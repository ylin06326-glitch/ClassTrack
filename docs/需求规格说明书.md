## 二、功能需求

### FR-01: 学生名单导入模块（双模式）

**优先级**: P0

**需求描述**:
1. **Excel导入**：支持 .xls / .xlsx 上传，智能识别姓名列，过滤表头
2. **纯文字导入**：textarea输入姓名，支持换行/逗号/顿号/空格分隔
3. 实时预览解析结果（显示将导入的姓名数量）
4. 双模式一键切换（Excel/文字标签）
5. 重名自动跳过，200人上限保护
6. 学生数据按班级隔离存储

### FR-02: 可视化拖拽分组功能（含多选批量拖拽）

**优先级**: P0

**需求描述**:
1. 分组数量：预设5/6/8组 + 自定义2-20组
2. 上下分区：上方横向分组栏位 + 下方学生名单池
3. **单选拖拽**：鼠标拖拽单个学生，可跨组调整
4. **多选拖拽**：点击选中多个学生 → 批量拖入目标组
   - 点击切换选中（蓝色高亮+✓标记）
   - Ctrl+点击追加 / Shift+点击范围选择
   - 全选/取消全选工具栏
5. 拖拽交互：半透明源+蓝色光晕目标+弹跳动画
6. 【确定锁定】固化分组布局
7. 【重新分组】全部重置

### FR-03: 日期选择 + 作业等级登记 + 催交

**优先级**: P0

**需求描述**:
1. 日期选择器 + 前一天/后一天/今天导航
2. 每位学生循环切换评级：未交→C→B→A→未交
3. 等级颜色：A绿/B蓝/C黄/未交粉
4. 等级与日期绑定存储
5. 批量设置（全部A/B/C/未交）
6. **催交通知**：列出当日未交学生（按分组整理）
   - 📋 复制名单到剪贴板
   - 🖨️ 打印通知单
   - 📥 导出催交名单Excel

### FR-04: 时段筛选 & Excel报表导出

**优先级**: P0

**需求描述**:
1. 双日期区间筛选器 + 日期校验
2. 数据预览表格（前200条）
3. 单学生台账导出 + 全班汇总导出
4. 含统计汇总行

### FR-05: 多班级切换管理

**优先级**: P0 (v1.1新增)

**需求描述**:
1. 创建/重命名/删除班级
2. 顶部下拉选择器快速切换
3. 管理Modal：列表展示+操作按钮
4. 所有数据按班级完全隔离
5. 删除班级级联清理数据
6. 至少保留一个班级
7. 兼容v1.0数据自动迁移

### FR-06: 删除学生

**优先级**: P0 (v1.1新增)

**需求描述**:
1. 学生卡片右上角×删除按钮（hover显示）
2. 二次确认弹窗
3. 级联删除关联作业记录

### FR-07: 可视化数据图表

**优先级**: P1 (v1.1新增)

**需求描述**:
1. Tab 4「📈 数据概览」
2. 4个统计卡片：总人数/已交/未交/A率
3. 环形饼图：当日A/B/C/未交分布
4. 分组对比柱状图：各组A率+未交对比
5. 14天趋势折线图：作业提交率变化

### FR-08: 程序打包+退出

**优先级**: P0 (v1.1新增)

**需求描述**:
1. PyInstaller单文件EXE（约34MB）
2. --windowed模式（无控制台窗口）
3. 界面⏻退出按钮 + shutdown API
4. data目录自动创建在exe同级

## 六、API接口清单 (v1.1)

### 班级管理 (新增5个)
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/classes | 列出所有班级 |
| POST | /api/classes | 创建班级 |
| PUT | /api/classes/<id> | 重命名班级 |
| DELETE | /api/classes/<id> | 删除班级（级联） |
| POST | /api/classes/<id>/activate | 切换活跃班级 |

### 导入 (新增1个)
| POST | /api/import/text | 纯文字导入名单 |

### 分组 (新增1个)
| PUT | /api/students/batch-move | 批量移动学生 |

### 作业 (新增1个)
| GET | /api/homework/missing | 获取未交学生列表 |

### 数据分析 (新增2个)
| GET | /api/analytics/overview | 数据概览（当日+分组对比） |
| GET | /api/analytics/trend | 近期趋势（提交率） |

### 系统 (新增1个)
| POST | /api/shutdown | 安全关闭服务器 |

**总计**: v1.0 (16个) + v1.1新增 (11个) = 27个API端点
