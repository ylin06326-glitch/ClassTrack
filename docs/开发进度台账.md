## 二、v1.1 新增功能清单

### 2.1 多班级切换管理 ✅
- [x] classes 表：支持创建/重命名/删除多个班级
- [x] 所有数据表增加 class_id 外键隔离
- [x] 自动数据库迁移（兼容v1.0数据）
- [x] 班级下拉选择器 + 管理Modal
- [x] 切换班级即时刷新全部数据
- [x] 删除班级级联删除关联数据
- [x] 至少保留一个班级保护

### 2.2 删除学生 ✅
- [x] 学生卡片右上角 × 删除按钮（hover显示）
- [x] 二次确认弹窗（Modal）
- [x] 级联删除关联作业记录
- [x] 分组栏和未分组池均支持删除

### 2.3 多选批量拖拽 ✅
- [x] 点击学生卡片切换选中状态（蓝色高亮+✓标记）
- [x] Ctrl+点击追加选择 / Shift+点击范围选择
- [x] 全选/取消全选工具栏
- [x] 拖动已选中卡片 → 所有选中学生批量移动
- [x] 批量移动API (/api/students/batch-move)
- [x] 拖拽时显示浮层提示"移动 N 名学生"

### 2.4 纯文字导入 ✅
- [x] Excel/文字双模式切换标签
- [x] 文字输入框（textarea）+ 实时姓名预览计数
- [x] 支持换行/逗号/顿号/空格分隔
- [x] 后端 /api/import/text 接口
- [x] 自动去重 + 200人上限保护

### 2.5 可视化数据图表（Tab 4: 📈 数据概览） ✅
- [x] 4个快捷统计卡片（总人数/已交/未交/A率）
- [x] 环形饼图（Chart.js）：当日 A/B/C/未交 占比
- [x] 分组对比柱状图：各分组A率+未交人数
- [x] 近14天提交率趋势折线图
- [x] 后端 /api/analytics/overview 和 /api/analytics/trend 接口

### 2.6 催交作业 ✅
- [x] 作业登记Tab增加"🔔 催交通知"按钮
- [x] Modal按分组列出所有未交学生
- [x] 📋 复制名单到剪贴板（可直接粘贴到微信/钉钉）
- [x] 🖨️ 打印通知单（格式化HTML打印页）
- [x] 📥 导出催交名单Excel
- [x] 后端 /api/homework/missing 接口

### 2.7 程序打包 ✅
